    Compartir archivos en la misma Wi-Fi

    Sin instalar apps ni crear cuenta. Los archivos no se suben a la nube. Cargar la web y emparejar dispositivos requiere internet.

    Transferir archivos entre Windows y Mac

    Conecta ambos equipos a la misma red, empareja sus navegadores con un código y arrastra documentos, vídeos o archivos ZIP para enviarlos.

    Pasar fotos del móvil al ordenador

    Conecta el móvil y el ordenador a la misma red local. Escanea el QR o introduce el código para compartir fotos, vídeos y documentos. Compatible con iPhone y Windows, sin instalar apps.

    Enviar texto y enlaces entre dispositivos

    Publica una URL, texto o código en el chat para todos los dispositivos conectados a la sala. Puedes seguir chateando mientras se transfieren los archivos.
