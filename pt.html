    Compartilhar arquivos no mesmo Wi-Fi

    Sem instalação ou conta. Os arquivos não são enviados para a nuvem. Carregar o site e parear dispositivos exige internet.

    Transferir arquivos entre Windows e Mac

    Conecte os dois computadores à mesma rede, pareie os navegadores com um código e arraste documentos, vídeos ou arquivos ZIP para enviar.

    Passar fotos do celular para o computador

    Conecte celular e computador à mesma rede local. Leia o QR ou digite o código para compartilhar fotos, vídeos e documentos. Compatível com iPhone e Windows, sem instalar apps.

    Enviar texto e links entre dispositivos

    Envie uma URL, texto ou código pelo chat para todos os dispositivos conectados à sala. Você pode continuar conversando enquanto os arquivos são transferidos.
